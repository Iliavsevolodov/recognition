# Recognition

Мини-сервис для сбора достижений участников перед сценическим признанием.

## Возможности

- публичная форма с двумя табами: **500 PV** и **Квалификация**;
- квалификации: S1, S2, L, L1 PRO, L2, L2 PRO, L3, L3 PRO;
- отдельная админка со статистикой, фильтрами, поиском, редактированием и удалением;
- подсчёт количества грамот по каждой квалификации;
- Telegram-уведомление после новой заявки через Supabase Edge Function.

## Страницы

- `index.html` — публичная форма;
- `admin.html` — админка.

Backend использует отдельные таблицы/RPC с префиксом `recognition_` в существующем Supabase-проекте Business Session Admin. Данные Business Session сервис не затрагивает.
